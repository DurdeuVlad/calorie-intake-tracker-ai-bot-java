# Support

This repository is a self-hosted reference implementation and is maintained on a best-effort basis.

## Before asking for help

1. Read the [local development guide](docs/local-development.md), [configuration reference](docs/configuration.md), and [operations runbook](docs/operations.md).
2. Search existing issues for the same symptom.
3. Reproduce without sharing tokens, Telegram identifiers, private messages, media, or database dumps.
4. Include the commit, Java version, deployment mode, and a redacted log excerpt.

Use a GitHub issue for reproducible bugs and feature requests. Use the private reporting process in `SECURITY.md` for vulnerabilities or data-isolation concerns. Please do not expect support for customized production infrastructure or leaked credentials.
